# 数据来源及许可

本地 `data/raw/Dry_Bean_Dataset.xlsx` 为 UCI Dry Bean 公开数据集的原始工作簿。Git 仓库通过 download_data.py 下载数据，不提交原始二进制工作簿。

来源：UCI Machine Learning Repository，Dry Bean，2020。

数据 DOI：https://doi.org/10.24432/C50S4B

数据集页面：https://archive.ics.uci.edu/dataset/602/dry+bean+dataset

数据集官方页面标注许可为 Creative Commons Attribution 4.0 International（CC BY 4.0）。

许可文本：https://creativecommons.org/licenses/by/4.0/

原始工作簿未修改。实验在内存中删除完全重复行，处理步骤与统计记录见 train.py 和 outputs/data_summary.json。许可仅适用于引用的公开数据集，未对课程课件内容设置新的许可。
